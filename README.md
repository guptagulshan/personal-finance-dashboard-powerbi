# Personal Finance Dashboard | Power BI

## Overview

This project is an interactive Power BI dashboard designed to analyze personal financial performance from 2020–2025.

The dashboard tracks income, expenses, savings, investments, and spending patterns across multiple categories while providing key financial insights through KPI cards and visual analytics.

## Tools Used

* Power BI
* DAX
* Data Modeling
* Data Visualization

## Dashboard Features

### KPI Cards

* Total Income
* Total Expenses
* Total Savings
* Total Investments
* Net Surplus

### Financial Ratios

* Savings Rate
* Investment Rate
* Expense Ratio

### Visualizations

* Income vs Expenses Trend
* Savings vs Investments Trend
* Expense Breakdown (Donut Chart)
* Expense Category Distribution (Treemap)

### Interactive Filters

* Year Slicer
* Month Slicer

## Key Insights

* Total Income: ₹3.48M
* Total Expenses: ₹2.53M
* Net Surplus: ₹948K
* Savings Rate: 15.09%
* Investment Rate: 12.52%
* Rent is the largest expense category (~39% of spending)
* Income consistently remained higher than expenses
